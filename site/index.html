Offline · read-only · CI-ready

Catch toolchain drift before you push.

lockstep cross-checks every place a Node, Bun, or package-manager version is declared — package.json, .nvmrc, asdf and mise files, the committed lockfile, and every GitHub Actions workflow — then reports the conflicts in one pass.

What it checks

Every source that pins a runtime or a package manager, read directly from the project. Missing files are simply skipped, and nothing is ever written back.

engines
The engines.node and engines.bun ranges in package.json — the versions the project claims to support.
packageManager
The manager and exact version Corepack reads from package.json, such as pnpm@9.12.0.
volta
The volta.node and volta.bun pins used by the Volta toolchain.
.nvmrc
The Node version nvm installs for the directory.
.node-version
The Node version read by nodenv and asdf-compatible tools.
.tool-versions
Per-tool version pins for asdf.
mise.toml
Node and Bun versions declared for mise.
Lockfiles
package-lock.json, yarn.lock, pnpm-lock.yaml, bun.lock, and bun.lockb, which reveal the manager actually in use.
GitHub Actions
Every .github/workflows/*.yml, including setup-node, setup-bun, and pnpm/action-setup pins and whether installs are frozen.

Quick start

Point it at one project. The summary comes first, then each declared source, then the findings. The exit code is the gate.

quick start 
# run it without installing$ bunx github:srivtx/lockstep#main# audit another project$ lockstep --dir path/to/project# machine-readable output, and fail CI on warnings$ lockstep --json --fail-on warning

Every flag, the exit-code scheme, and JSON output are in Usage.

Rule explorer

Ten stable codes. Each finding carries one, a severity, and the file it points at.

LOCK-001
error Conflicting Node versions across sources.
LOCK-002
error packageManager conflicts with the committed lockfile.
LOCK-003
error Multiple lockfiles from different managers.
LOCK-004
warning Lockfile committed but CI does not install frozen.
LOCK-005
warning No lockfile committed.
LOCK-006
warning packageManager declared but CI never enables corepack.
LOCK-007
info engines.node range does not include the CI-pinned Node.
LOCK-008
info .nvmrc and .node-version differ only cosmetically.
LOCK-009
warning CI bun-version major disagrees with engines.bun.
LOCK-010
info No GitHub Actions workflow found so CI cannot be verified.
